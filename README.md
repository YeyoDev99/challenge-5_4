## Domain
**Education Systems** — Cluster U.S. public schools by resource, demographic, and structural
features using the NCES Common Core of Data (CCD) SY 2022-23. The goal is to discover whether
the found groups reflect known urban/rural or socioeconomic divisions.

## Dataset
**NCES Common Core of Data (CCD) — Public Elementary/Secondary School Universe Survey**  
School Year: 2022-2023 | ~99,500 open public schools

### How to Download the Data
1. Go to https://nces.ed.gov/ccd/files.asp
2. Set filters: **Fiscal/Nonfiscal = Nonfiscal**, **Level = School**, **School Year = 2022-2023**
3. Download and unzip these 5 files into the `data/` folder:

| File code | Content | File name pattern |
|---|---|---|
| 029 | Directory (school info, charter, level) | `ccd_sch_029_2223_w_1a_083023.csv` |
| 033 | Lunch Eligibility (FRPL — poverty proxy) | `ccd_sch_033_2223_l_1a_083023.csv` |
| 052 | Membership (enrollment by race/ethnicity) | `ccd_sch_052_2223_l_1a_083023.csv` |
| 059 | Staff (teacher FTE counts) | `ccd_sch_059_2223_l_1a_083023.csv` |
| 129 | School Characteristics (virtual, NSLP) | `ccd_sch_129_2223_w_1a_083023.csv` |

> The data files are NOT included in this repository (public use; download from NCES).

## Quickstart

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Place data files
Download from NCES (see above) and place the 5 CSV files in `data/`.

## Downloading the Data

The CSV files are not included in this repository (too large for GitHub).
Run the download script to get them automatically:

```bash
bash download_data.sh
```

This downloads all 5 CCD files directly from NCES into the `data/` folder.
It takes about 5 minutes depending on your connection.

### 3. Run the notebook
```bash
jupyter notebook notebooks/best_run.ipynb
```
Run all cells in order. All figures are saved to `figures/` and metrics to `results/`.

### All random seeds are fixed
- `random_state = 42` for all stochastic algorithms (K-Means, PCA)
- Stability checked with additional seeds: 7, 123

## Algorithms

| Algorithm | Key Config |
|---|---|
| **K-Means** | k selected via elbow + silhouette (k ∈ {2..12}), k-means++, n_init=20 |
| **DBSCAN** | eps from k-NN distance plot, min_samples = 2×n_features |
| **Hierarchical** | Ward linkage, same k as K-Means; dendrogram on 5K sample |

## Evaluation Metrics
All three algorithms evaluated with: **Silhouette Score**, **Davies-Bouldin Index**, **Calinski-Harabasz Index**  
DBSCAN additionally reports **noise fraction**.  
Adjusted Rand Index vs `LEVEL` used **post-hoc only** (never for tuning).
