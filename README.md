# Challenge 5 — Unsupervised Learning: Clustering Education Systems
## Group 4 · NCES CCD SY 2022-23
### Universidad Distrital Francisco José de Caldas — Machine Learning

---

## Domain
**Education Systems** — Cluster ~99K U.S. public schools by resource, demographic,
and structural features to discover whether the found groups reflect known urban/rural
or socioeconomic divisions.

**Dataset:** NCES Common Core of Data (CCD) SY 2022-23  
**Source:** https://nces.ed.gov/ccd/files.asp  
**Algorithms:** K-Means · DBSCAN · Hierarchical (Agglomerative)

---

## How to Run

There are **two ways** to run this project. Choose the one that works for you.

---

### Option A — Docker (recommended, works on any machine)

**Requirements:** Docker Desktop installed → https://www.docker.com/products/docker-desktop

```bash
# 1. Clone the repo
git clone https://github.com/YOUR_USERNAME/challenge-5_4.git
cd challenge-5_4

# 2. Download the data files automatically
docker-compose run download

# 3. Start JupyterLab
docker-compose up notebook
```

**4.** Open your browser at: **http://localhost:8888**  
**5.** Navigate to `notebooks/` → double-click `best_run.ipynb`  
**6.** Click **Run → Run All Cells**

> All results (figures, metrics, CHECKLIST.md) are saved to your local folders
> automatically because the `data/`, `figures/`, and `results/` folders are mounted.

---

### Option B — GitHub Codespaces (no installation needed)

**Requirements:** A GitHub account and a browser.

**1.** Open the repo on GitHub → click **Code → Codespaces → Create codespace**

**2.** In the Codespace terminal:
```bash
# Download data
bash download_data.sh

# Install dependencies
pip install -r requirements.txt

# Start JupyterLab
jupyter lab
```

**3.** Copy the URL with the token that appears and open it in your browser.

**4.** Navigate to `notebooks/` → open `best_run.ipynb` → **Run → Run All Cells**

> ⚠️ Data files are lost when the Codespace stops. Run `bash download_data.sh`
> again each time you reopen the Codespace.

## Algorithms & Features

**Features (11):** log_enrollment, pct_free_reduced_lunch, pct_white, pct_hispanic,
pct_black, pct_asian, pct_multirace, student_teacher_ratio, is_charter, is_virtual,
school_level_enc

| Algorithm | Configuration | Note |
|---|---|---|
| K-Means | k=6, MiniBatchKMeans, n_init=20 | Full dataset (95K schools) |
| DBSCAN | eps=1.21, min_samples=16 | Sample n=15,000 |
| Hierarchical | k=6, Ward linkage | Sample n=5,000 |
