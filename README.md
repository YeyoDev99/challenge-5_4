# Challenge 5 - Clustering

## Objetivo
Aplicar K-Means, DBSCAN y clustering jerárquico para descubrir patrones en datos educativos.

## Algoritmos usados
- K-Means
- DBSCAN
- Agglomerative Clustering

## Pipeline
- Limpieza de datos
- Normalización
- PCA
- Clustering
- Evaluación con métricas

## Métricas
- Silhouette Score
- Davies-Bouldin Index
- Calinski-Harabasz Index

## Conclusión
Se comparan los algoritmos y se analizan clusters en contexto educativo.
